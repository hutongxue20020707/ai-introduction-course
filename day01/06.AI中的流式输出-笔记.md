## 0. 这节课要解决什么

前面几节（01~03）都是同一个套路：**等模型把整段话生成完，再一次性打印**。
回答一长，屏幕就白着等好几秒，体验很差。

这一节解决的就是它 —— **边生成、边显示**（打字机效果）。

老师课上的两句原话，正是本节的全部内容：

> 使用循环来获取AI的内容并输出在控制台
> 在控制台上输出内容不换行

---

## 1. 流式 vs 非流式

| | `stream=False`（前几节） | `stream=True`（本节） |
| --- | --- | --- |
| 返回方式 | 全部生成完，一次性返回一整段 | 生成一点返回一点（一小片叫 chunk） |
| 等待感受 | 长回答要干等几秒到几十秒 | **本机实测：第一个字 0.47 秒就出现** |
| 取内容 | `res.choices[0].message.content` | `for chunk in res:` → `chunk.choices[0].delta.content` |
| 适合场景 | 后台批处理、需要一次拿到完整结果 | 聊天界面、控制台交互、要"看着它在打字" |

> 注意一个容易混的点：**非流式用 `message`，流式用 `delta`**。
> `message` 是"完整的一条消息"，`delta` 是"这一小片新增的内容"。

## 3. 完整代码（核心部分）

```python
import os
import sys

if hasattr(sys.stdout, "reconfigure"):     # 防模型回复里的 emoji 把程序搞崩
    sys.stdout.reconfigure(errors="replace")

from dotenv import load_dotenv
from openai import OpenAI

THINKING = "disabled"
MODEL = "deepseek-flash"

load_dotenv(override=True)
api_key = os.environ.get("DEEPSEEK_API_KEY")
if not api_key:
    raise SystemExit("没有读到 DEEPSEEK_API_KEY，请确认项目目录下有 .env 文件。")

client = OpenAI(api_key=api_key, base_url="https://api.deepseek.com")

prompt = "你是一名电信行业的专家，请问如何进入到在这个行业并深耕？"
print("我：", prompt)
print("AI：", end="", flush=True)

res = client.chat.completions.create(
    model=MODEL,
    messages=[{"role": "user", "content": prompt}],
    stream=True,                                    # ← 本节主角，就这一个开关
    extra_body={"thinking": {"type": THINKING}},
)

for chunk in res:
    if not chunk.choices:                           # 稳妥：有的分片没有 choices
        continue
    delta = chunk.choices[0].delta.content
    if delta:                                       # 稳妥：有的分片正文是 None
        print(delta, end="", flush=True)

print()
```

---

## 4. 逐行拆解（重点看最后两行）

| 代码 | 作用 |
| --- | --- |
| `stream=True` | 打开流式。不加就是前几节的一次性返回 |
| `for chunk in res:` | 返回的不是一整条消息，而是一个**可迭代的流**，每转一圈拿到一小片 |
| `chunk.choices[0].delta.content` | 取这一小片的**新增正文**。注意是 `delta` 不是 `message` |
| `if delta:` | 有的分片正文是 `None`（比如只带结束标记的那片），不判断就会打出一串 `None` |
| **`end=""`** | **不换行**。默认 `print` 会换行，不加这句每片都另起一行，输出会变成一条竖线 |
| **`flush=True`** | **立刻刷到屏幕上**。不加的话 Python 会把内容攒在缓冲区里，看着像"卡住了，然后一次性全出来" |

> 这两个参数（`end=""` 和 `flush=True`）就是老师说的"输出内容不换行"的完整实现。
> 只写 `end=""` 在多数终端还行，但加上 `flush=True` 才稳定有打字机效果。

## 5. 本机实测数据（2026-10-12，`deepseek-flash`）

| 指标 | 实测值 |
| --- | --- |
| 一次长回答收到多少分片 | **1542 片**（对应 1400 多个输出 token） |
| 其中正文为 `None` 的分片 | **0 片** |
| 第一个字出现的时间 | **0.47 秒** |
| 短回答（一句话）的分片数 | 26 片 |

两个结论：

1. **老师的原版代码为什么没崩**：本机这个模型一次也没返回 `None` 分片，所以不判断也侥幸没事。但不同模型、不同服务商、不同参数下**可能出现空分片**，加上 `if delta:` 才稳 — 这是本课给你补的保险。
2. **流式的价值在"首字延迟"**：整段回答要好几秒才生成完，但第一个字 0.5 秒内就来了。用户体验的差别就在这里。

## 6. 进阶：流式也能统计 token 消耗

流式默认**不带用量**（因为还没生成完）。想让最后一片带上，加一个参数：

```python
res = client.chat.completions.create(
    model=MODEL,
    messages=[{"role": "user", "content": "用一句话说明什么是流式输出"}],
    stream=True,
    stream_options={"include_usage": True},     # ← 关键
)

usage = None
for chunk in res:
    if getattr(chunk, "usage", None):           # 带用量的那一片
        usage = chunk.usage
    if not chunk.choices:
        continue
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)

print()
if usage:
    print(f"(tokens：输入 {usage.prompt_tokens} / 输出 {usage.completion_tokens})")
```

本机实测输出：

```
流式输出是指模型生成内容时逐字或逐词实时返回，而非等全部生成完毕后再一次性输出。
(tokens：输入 11 / 输出 25)
```

## 7. 代码编写报错原因以及解决办法

| 报错信息 / 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| 输出里混着 `None`（如 `你好None，我是None`） | 分片正文是 `None`，没判断就打印 | `delta = chunk.choices[0].delta.content` 之后加 `if delta:` |
| 内容**卡住不动，然后一次性全蹦出来** | 没加 `flush=True`，内容攒在缓冲区 | `print(delta, end="", flush=True)` |
| 输出变成**一列竖着的字**（每片一行） | 忘了 `end=""`，`print` 默认换行 | 加上 `end=""` |
| `TypeError: 'ChatCompletion' object is not iterable` | 忘了写 `stream=True`，却用 `for chunk in res` 循环 | 补上 `stream=True`；非流式要用 `res.choices[0].message.content` |
| `AttributeError: 'NoneType' object has no attribute 'content'` | 写了 `stream=True`，却还按非流式取 `res.choices[0].message` | 流式要用 `res.choices[0].delta.content`；或者改回 `stream=False` |
| `IndexError: list index out of range` | `chunk.choices` 是空列表（换参数/服务商时会出现），却直接取 `[0]` | 先判断 `if not chunk.choices: continue` |
| 打字机效果"一顿一顿" | 网络和模型吐字速度导致，正常现象 | 无需处理 |
| `UnicodeEncodeError: 'gbk' ...` | 回复里有 emoji | 脚本开头 `sys.stdout.reconfigure(errors="replace")` |
