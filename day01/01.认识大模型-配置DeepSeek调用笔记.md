## 0. 这节课要解决什么

"认识大模型"这一节，本质是把一句话变成一次真实的模型调用：

> **让电脑通过代码，把问题发给大模型，再把大模型的话拿回来打印在控制台上。**

只要打通这条链路，后面的所有 AI 应用（聊天机器人、文档问答、AI 编程助手）都是在这条链路上加功能。

一次成功的大模型调用，只有 **3 个要素**：

| 要素 | 是什么 | DeepSeek 的值 |
| --- | --- | --- |
| API Key | 你的"身份证 + 钱包"，代表你的账号和余额 | 到 platform.deepseek.com 申请，`sk-` 开头 |
| 请求地址 base_url | 代码往哪个服务器发请求 | `https://api.deepseek.com` |
| 模型名 model | 具体用哪一个模型 | `deepseek-flash` 或 `deepseek-v4-pro` |

记住这三样，TraeCode 里配自定义模型、自己写 Python 代码，填的都是这三个值。

## 3. 配置 DeepSeek 的调用

### 3.1 路线 A（备选）：直接用内置 DeepSeek 模型（0 配置）

> 本课**不走**这条路线，但它是免费的、最适合"让 AI 帮我写代码"的场景，保留在这里。
> **路线 A 不需要 API Key，也不需要写代码**，它只影响 TraeCode 的 AI 对话面板。

1. 打开 AI 对话框，在**输入框右下角**点当前模型名，弹出模型列表；
2. 选 **DeepSeek-V4.1-Flash**（快、便宜，日常够用）或 **DeepSeek-V4-Pro 正式版**（更强，适合复杂推理）；
3. 鼠标悬停在模型名上可以看到它支持的能力（思考模式、图像理解等）。
4. 直接提问即可，不需要填任何 Key。

### 3.2 路线 B：添加自定义模型（用自己申请的 DeepSeek API Key）✅ 本课采用

本机实测环境：**TraeCode CN 3.3.102**，安装位置 `D:\TraeCode CN\Trae CN\`，用户配置目录 `C:\Users\20162\.trae-cn`。

入口有两个，任选：

- **设置 → 模型 → 添加模型**；
- 或者 **AI 对话框的模型清单 → 添加模型**。

在"添加模型"窗口里：

1. 选择 **自定义模型 / 自定义配置**（不要选预设服务商那一栏）；
2. 按下表填写：

| 参数 | 填什么 | 说明（踩坑点） |
| --- | --- | --- |
| API 格式 | **OpenAI** | 没有特殊理由就选 OpenAI；DeepSeek 兼容 OpenAI 协议 |
| 请求地址（Base URL） | `https://api.deepseek.com` | **不要**自己加 `/chat/completions`；"完整 URL"开关保持**关闭** |
| 模型 ID / 模型名称 | `deepseek-flash` 或 `deepseek-v4-pro` | ⚠️ 必须和官方一字不差，写错就"请求失败" |
| API Key / 鉴权 | 你申请的 `sk-...` | 粘贴后注意首尾不要有空格 |
| 模型展示名 | 随便起，如 `DeepSeek-Flash` | 只影响你在列表里看到的名字 |

3. 保存。然后在对话框右下角把模型切换成刚才添加的那个，发一句"你好"测试。
4. 如果保存时就报 **"请填写所有必填字段"**：通常是**模型名称那一栏没选/没填**——点下拉箭头选一个，或者手动输入 `deepseek-flash`。

> 一句话记忆：**地址 `https://api.deepseek.com`，模型名 `deepseek-flash`。**

## 4. 如何申请 DeepSeek 的密钥（API Key）

（原笔记里是"智谱 AI 官网的密钥"，流程完全一样，这里换成 DeepSeek 官方平台。）

1. 打开 **`https://platform.deepseek.com`**，注册 / 登录（手机号或邮箱）。
2. 进 **API Keys** 页面 → **创建 API Key** → 起个名字（如 `trae-day01`）。
3. **立即复制**弹出的 `sk-` 开头的字符串。**它只完整显示这一次**，关掉窗口就再也看不到了，只能重建。
4. 到 **充值 / 余额** 页面充一点钱（API 是按 token 计费付费的，几块钱就够练习很久）。
5. 想省钱的技巧：DeepSeek 采用峰谷定价，**北京时间周一至周五 9:00–12:00、14:00–18:00 是高峰时段，其余时间（含周末）价格为一半**。练习课尽量安排在晚上或周末跑。

**拿到 Key 之后（本机已经提前准备好了，只剩这一步）**

6. 打开项目里的 `.env`（本机已生成，内容见下），把 `sk-在这里粘贴你的密钥` 整段替换成真实密钥，保存；
7. 回到终端跑 `python scripts/test_connection.py`，看到"路线 B 已打通"就成功了。

```
# .env 的内容（= 左边是变量名，不要动；= 右边是你的密钥）
DEEPSEEK_API_KEY=sk-在这里粘贴你的密钥
```

> 已经配套生成 `.gitignore`，里面写了 `.env`，所以密钥不会误传到 Git。

### 密钥安全（作业会检查这一条）

**密钥优先级：环境变量 > `.env`** —— 这是最容易踩的坑，本机真实踩过（见第 6 节 ascii 报错那行）。
所以代码里统一写 `load_dotenv(override=True)`，让 `.env` 说话算数；怀疑被污染时先 `echo $env:DEEPSEEK_API_KEY` 查一下。

- ❌ 不要把 Key 直接写死在 `main.py` 里；
- ❌ **也不要拿密钥当判断条件**，比如 `if not api_key.startswith("sk-8da9c...")`——这是本机真实踩过的坑：表面上像"更严格校验"，实际是①换密钥就失效 ②把密钥抄进了源码文件；
- ✅ 源码里只做通用格式检查（`api_key.startswith("sk-")`），真实密钥只放 `.env`；
- ✅ 放在项目根目录的 `.env` 文件里，代码用 `python-dotenv` 读取；
- ✅ `.env` 不要提交到 Git / 不要发群里；仓库里只放 `.env.example` 模板；
- ⚠️ Key 一旦泄露（发过聊天、截过图、进过源码），别人可以用你的余额，立刻到平台**删除重建**。

### 让 TraeCode 的 AI 也看不到密钥

TraeCode 的 AI 会把项目文件读进去当上下文，所以密钥文件必须排除。**两道保险，本机已经装好**：

**第一道：`.gitignore`** —— TraeCode 默认就忽略 `.gitignore` 里列出的文件，本项目的 `.gitignore` 第一行就是 `.env`。

**第二道：`.trae/.ignore`** —— 这是 TraeCode 额外的忽略清单，本机已创建两份（工作区根目录和项目目录各一份）：

```
.env
**/.env
.env.*
**/.env.*
__pycache__/
*.pyc
```

被忽略的文件**不参与代码索引，也不能作为 `#Workspace` / `#Folder` 上下文喂给 AI**。
（如果想让改动立刻生效：设置 → 索引与文档 → 上下文 → 代码索引管理 → 点 **Build** 重新索引。）

**第三道（靠习惯）**：不要手动把 `.env` 拖进对话上下文，也不要在对话里粘贴密钥。

> **本课的选择：不给 TraeCode 配置自定义模型。**
> TraeCode 的 AI 对话用它自带的**内置模型**（走 TraeCode 的额度，不消耗你 DeepSeek 账号的钱）；
> 你自己的密钥只给"自己写的代码"用（`python 01.认识大模型.py`）。两边互不影响，密钥也不用交给 IDE。

## 5. 最终案例代码：调用 DeepSeek 并打印回复

### 5.1 依赖：`requirements.txt`

```
openai>=1.40.0
python-dotenv>=1.0.0
```

### 5.2 主程序：`main.py`

```python
import os
from openai import OpenAI
from dotenv import load_dotenv

load_dotenv()  # 读取同目录下的 .env

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",   # 关键：换成 DeepSeek 的地址
)

response = client.chat.completions.create(
    model="deepseek-flash",                # 模型名必须是官方认可的 ID
    messages=[
        {"role": "system", "content": "你是一个耐心的 Python 助教，回答要简短。"},
        {"role": "user",   "content": "用一句话解释什么是大语言模型。"},
    ],
    stream=False,
)

print(response.choices[0].message.content)
```

### 5.3 关键行逐条解释

| 代码 | 作用 |
| --- | --- |
| `OpenAI(api_key=..., base_url=...)` | 创建一个"客户端"。SDK 名字叫 OpenAI，但地址指向 DeepSeek，所以连的是 DeepSeek 的服务器 |
| `messages` | 对话历史，是一个列表。`system` 是给模型的人设/规则，`user` 是用户提问，`assistant` 是模型之前的回答 |
| `model="deepseek-flash"` | 选用哪个模型；想用更强推理就换 `deepseek-v4-pro` |
| `stream=False` | 一次性返回完整结果；改成 `True` 就是流式（打字机效果，见 `stream_demo.py`） |
| `response.choices[0].message.content` | 取出模型回复的**文本**——这就是"AI 回复的内容" |
| `print(...)` | 打印到控制台 |

### 5.5 为什么回复会是空的？—— 思考模式与 token 账

DeepSeek V4 系列**默认开启"思考模式"**：模型先"想"一段再回答。想的过程不出现在 `content` 里（它在另一个字段 `reasoning_content`），但**照样计费**。

本机实测（2026-09-20，问"只回复两个字：通了"）：

| 设置 | 输出 tokens | 其中思考 | 回复内容 |
| --- | --- | --- | --- |
| 默认（思考开着） | 121 | 119 | `通了` |
| `thinking={"type": "disabled"}` | **1** | 0 | `通了` |
| 思考开 + `reasoning_effort="low"` | 25 | 23 | `通了` |

两个实用结论：

1. **`max_tokens` 给小了会得到"空回复"**：思考过程先把额度吃光，`content` 就成了空字符串。本机第一次就踩到了——`max_tokens=32` 时回复是空的，改成 200 才有内容。
2. **日常练习关掉思考更省钱**：同一个问题 121 tokens 对 1 token，差一百多倍。

关/开思考的写法：

```python
extra_body={"thinking": {"type": "disabled"}}   # 关：快、省（练习推荐）
extra_body={"thinking": {"type": "enabled"}}    # 开：先想再答（推理题推荐）
reasoning_effort="low"                          # 思考强度：low / high / max
```

本课三个脚本顶部都留了 `THINKING = "disabled"` 开关，想看"边想边答"改成 `"enabled"` 即可。

## 6. 代码编写报错原因以及解决办法

按报错关键词查表：

| 报错信息（关键词） | 原因 | 解决办法 |
| --- | --- | --- |
| `ModuleNotFoundError: No module named 'openai'` | 依赖没装，或装到了别的 Python 环境 | 在**项目所在**终端执行 `pip install -r requirements.txt`；再 `pip list` 确认 |
| `python : 无法将"python"项识别为...` / `'python' 不是内部或外部命令` | Python 没装，或安装时没勾"Add to PATH" | 重装 Python 并勾选 Add python.exe to PATH；重启 TraeCode；或用绝对路径 `C:\...\python.exe main.py` |
| `AuthenticationError` / `401` / `invalid api key` | Key 写错、过期、被删，或粘贴时带了空格/引号 | 重新从平台复制；`.env` 里不要加引号；确认没把 `sk-` 漏掉 |
| `Insufficient Balance` / `402` | 账户余额为 0 | 到 platform.deepseek.com 充值 |
| `NotFoundError` / `model not found` / `Model Not Exist` | 模型名写错，**最常见的是还在用旧名 `deepseek-chat`、`deepseek-reasoner`** | 改用 `deepseek-flash` 或 `deepseek-v4-pro`（旧名已于 2026-07-24 停用） |
| `RateLimitError` / `429` | 请求太频繁、并发超限 | 加 `time.sleep(1)`、减少循环调用次数 |
| **回复内容是空的**（`content` 为空字符串，但接口没报错） | ① `max_tokens` 太小，额度被"思考模式"吃光了（本机实测：`max_tokens=32` → 空回复，改成 200 → 正常）；② 只看了 `content`，内容其实在 `reasoning_content` 里 | 把 `max_tokens` 调大（如 200）；或加 `extra_body={"thinking": {"type": "disabled"}}` 关掉思考模式（见 5.5） |
| `APIConnectionError` / `Connection error` / 超时 | 网络不通、代理/VPN 干扰 | 关掉 VPN/代理重试；或设置环境变量 `$env:HTTPS_PROXY="http://127.0.0.1:7890"` |
| 控制台中文乱码 / `UnicodeEncodeError: 'gbk' codec can't encode character '\u2705'` | Windows 终端默认编码是 GBK，**这个 emoji 本身就打不出来**（本机 2026-09-20 实测踩到：`print("环境就绪 ✅")` 直接让程序崩掉） | ① 最省事：**别在 print 里用 emoji**，改用中文/ASCII（`[OK]`、`环境就绪`）；② 或在终端执行 `chcp 65001` 切成 UTF-8；③ 或运行前 `$env:PYTHONIOENCODING="utf-8"` |
| Trae 里自定义模型"请求失败" | ① 模型 ID 与官方不一致；② 请求地址多带了 `/chat/completions`；③ Key 有空格 | 模型 ID 填 `deepseek-flash`；地址只填 `https://api.deepseek.com`；重新粘贴 Key |
| `UnicodeEncodeError: 'ascii' codec can't encode characters in position 7-10` （**不是** gbk 那条） | 密钥里有**非 ASCII 字符（中文）**。两个来源：① `.env` 里写的就是中文字；② **系统里有一个同名的用户环境变量**——本机 2026-09-21 真实踩到：`DEEPSEEK_API_KEY=申请秘钥`（就是老师笔记里 `Zhipuai(api_key="申请秘钥")` 那句被原样设成了环境变量），而 `load_dotenv()` **默认不覆盖已存在的环境变量**，于是 `.env` 里的真密钥被它顶掉了。`"Bearer "` 正好占 7 个字符，所以报错位置从 7 开始 | ① 先查有没有被环境变量污染：终端执行 `echo $env:DEEPSEEK_API_KEY`；② 有就删掉：`[Environment]::SetEnvironmentVariable('DEEPSEEK_API_KEY',$null,'User')`，然后**重开终端**；③ 代码里用 `load_dotenv(override=True)`，让 `.env` 优先；④ 确认 `.env` 里是真密钥 |
| 提示"密钥不对 / 没读到密钥"，**但 `.env` 明明填了真实密钥** | ① 跑的不是项目里那个文件——比如跑到了 `__pycache__\` 里的旧副本（本机 2026-09-21 真实踩到：整个项目的文件被搬进了 `__pycache__`）；② 有人把判断条件改成了硬编码整串密钥（`api_key.startswith("sk-你的密钥")`），换密钥后就永远不匹配 | ① 看清终端里的路径，必须是 `...\agent\01.认识大模型.py`，不是 `...\agent\__pycache__\...`；`__pycache__` 是 Python 自动生成的缓存目录，**里面的东西不要当代码跑**，可直接删除；② 判断条件写通用的 `startswith("sk-")`，**永远不要把密钥写进源码** |
| 换新密钥后脚本又报错 / 密钥出现在源码或截图里 | 密钥被硬编码进了 `.py` 文件，或已外泄 | 源码里只做格式检查（`startswith("sk-")`），真实密钥只放 `.env`；已外泄的密钥立刻到平台**删除重建** |
| `.env` 里的 Key 读不到（`api_key=None`） | `.env` 文件名写成了 `env` / `.env.txt`，或不在运行目录 | 确认文件名就是 `.env`（Windows 需打开"显示文件扩展名"）；`.env` 与 `main.py` 同级 |

## 7. AI 回复的内容在控制台输出打印

### 7.1 最简形式（非流式）

```python
print(response.choices[0].message.content)
```

### 7.2 常用增强写法

```python
# 1) 打印完整返回值对象，用于调试（能看到 token 用量、finish_reason）
print(response)

# 2) 打印 token 消耗（关心费用时很有用）
print(response.usage)

# 3) 加个分隔线，输出更好看
print("=" * 30)
print("AI：", response.choices[0].message.content)
print("=" * 30)
```

### 7.3 流式输出（打字机效果）

```python
stream = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "用三句话介绍你自己"}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)   # flush=True 让字符立刻显示
print()
```

`flush=True` 是流式打印的关键：不加的话，Python 会攒够一批才输出，看起来就像"卡住了突然全出来"。

### 7.4 想打印思考过程（可选）

V4 系列默认开启思考模式，思考内容在另一个字段里；只是打印回答的话，上面的写法就够了。
